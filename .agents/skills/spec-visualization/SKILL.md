# 规格可视化

## 概述

使用可视化材料来降低布局、流程、状态流转和系统关系中的歧义。可视化产物有助于讨论，但绝不能替代正式规格更新。

## 适用场景

- 线框图与页面结构
- 用户旅程与分支流程
- 状态图
- 架构或依赖关系草图
- 方案对比图

## 规则

- 可视化输出应保存在 `docs/superpowers/visuals/`
- 得出的结论必须回写到 `design` 或 `spec delta`
- 禁止把原型图、流程图或白板内容视为最终事实来源
