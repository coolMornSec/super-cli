# Host Fallback

## 目的

当宿主环境能力不足时，给出降级策略，避免工作流中断。

## 常见限制

- 不能运行浏览器测试
- 不能启动长期后台任务
- 不能调用子代理
- 不能访问外部网络
- 不能自动执行完整验证

## 降级策略

- 浏览器测试不可用时，改为基于代码和逻辑做静态验证建议
- 子代理不可用时，改为单代理分步推进
- 无法跑完整测试时，明确标记为未验证并说明原因
- 无法确认外部依赖时，列入待确认项

## 输出要求

- 必须明确说明当前限制
- 不得把未验证内容描述成已验证
- 不得隐瞒降级后的风险
