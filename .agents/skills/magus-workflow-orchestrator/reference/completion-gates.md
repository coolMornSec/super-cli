# Completion Gates

## 总体门禁

在宣称任务完成前，必须满足：

- 产物已经落位到文件或代码，而非只停留在对话中
- 已区分已验证、未验证、待确认三类条目
- L4 任务有规格记录、验证记录或等价说明
- 风险、边界、兼容性影响至少有一行说明
- 已明示宿主能力限制
- 遵守仓库 `AGENTS.md` 与用户已确认项
- 若 L4 中补充了需求，L3 与 L4 已同步并可追溯

## L1 门禁

- 已经给出直接回答、解释或澄清问题
- 未误入需求、规格或开发产物输出

## L2 门禁

- 已说明分析依据
- 已给出明确建议或对比结论
- 未伪装成正式需求或开发计划

## L3 门禁

- 需求已结构化
- 需求边界、约束、验收口径已表达清楚
- 未输出规格说明或开发计划

## L4 门禁

- 需求已引用或确认
- 已加载 `levels/L4-standard-dev.md`，并在 `workflow-state.md` 记录必要技能和场景技能加载状态
- 已生成任务规格与计划
- 规格与设计阶段已有 `contracts/` 产物
- 已给出验证与风险说明
- 需求变更或偏移已显式记录，并由用户确认处理路径
