# L1 - Chat and Q&A

## 定位

L1 是最轻量的工作流，负责处理闲聊、通用咨询、仓库相关问答与初步澄清。

## 适用场景

- 用户随便闲聊
- 用户问与仓库无关的问题
- 用户问仓库相关内容，但只是在了解、解释、确认概念
- 任务目标不明确，需要先问清楚
- 输入信息不足，暂时不能进入分析、需求或开发工作流

## 典型输出

- 简短回答
- 概念解释
- 澄清问题
- 对话式建议

## 不进入的内容

- 不做正式分析结论
- 不整理需求文档
- 不产出规格说明
- 不进入开发计划或实施拆解

## 路由提示

如果用户的问题只是为了聊天、确认概念、快速问答，优先进入 L1。
