# 菜单管理需求文档

## 1. 需求概述

菜单管理用于维护系统菜单结构与菜单基础信息，支持菜单树形展示、菜单新增/编辑/删除、批量删除，以及菜单基本信息维护与子菜单管理。

本期菜单管理以系统后台菜单维护为边界，只处理菜单基础信息、父子层级、排序、路径、访问类型与删除规则；不包含角色授权、按钮权限、菜单图标、菜单显隐控制、拖拽排序、动态路由生成规则等扩展能力。

## 2. 页面结构

菜单管理页采用左右分栏布局：

```
├──────────────────┬──────────────────────────────────┤
│                  │                                  │
│                  │  ┌─────────────────────────────┐ │
│  - 菜单树（搜索） │  │ 列表内容                     │ │
│                  │  │                             │ │
│                  │  └─────────────────────────────┘ │
└──────────────────┴──────────────────────────────────┘
```

## 3. 功能需求

### 3.1 左侧菜单树区

#### 3.1.1 搜索功能

- 支持菜单名称关键字过滤
- 输入后实时过滤菜单树
- 支持清空搜索

#### 3.1.2 菜单树展示

- 展示完整的菜单层级结构
- 支持展开/收起节点
- 点击节点后加载右侧详情
- 当前选中节点高亮显示
- 默认激活根节点
- 根节点为虚拟节点，用于承载最初没有父节点的一级菜单
- 默认激活虚拟根节点时，右侧子菜单列表展示一级菜单
- 虚拟根节点不作为真实菜单数据维护，不参与编辑、删除与批量删除

#### 3.1.3 菜单树刷新

- 支持手动刷新表数据

### 3.2 右侧编辑区

#### 3.2.1 子菜单列表

**查询区：**

- 查询条件：`菜单名称`、`菜单编码`
- 操作：`查询` 按钮
- 子菜单列表只展示当前选中菜单的直接子菜单
- 选中虚拟根节点时，子菜单列表展示一级菜单
- 查询仅在当前选中节点的直接子菜单范围内生效

**工具区：**

- `新增` 按钮：打开新增菜单页面
- `批量删除` 按钮：删除已勾选的子菜单（无勾选时禁用）

**列表区：**

- 字段：`序号`、`菜单名称`、`菜单编码`、`菜单路径`、`操作`
- 行操作：`编辑`、`删除`
- 支持复选框多选（含表头全选）
- 分页展示

**列表交互：**

- 编辑：打开编辑菜单页面，修改菜单信息
- 删除：单行删除，需二次确认

### 3.3 新增菜单页面

- 点击新增按钮后，打开新增菜单页面。
- 页面包含与基本信息 Tab 相同的表单字段，重置按钮用于清空表单，确认按钮用于保存新增子菜单。
- 新增菜单时，需要传递父菜单id。
- 从虚拟根节点新增菜单时，新增结果为一级菜单。
- 新增菜单时，由用户输入菜单名称并自动生成规则菜单编码。
- 新增菜单成功后，默认返回主页面，刷新列表树、菜单列表，新菜单按照排序值展示在父菜单下。

### 3.4 编辑菜单页面

- 点击编辑按钮后，打开编辑菜单页面。
- 页面包含与基本信息 Tab 相同的表单字段。
- 编辑菜单时，需要传递父菜单id、菜单id。
- 编辑菜单页面能力与基本信息 Tab 编辑能力保持一致。
- 编辑菜单成功后，默认返回主页面，刷新列表树、子菜单列表，编辑后的菜单显示在列表中。

## 4. 业务规则

- 菜单名称为必填项，未填写不可提交。
- 新增菜单时，由用户输入菜单名称并自动生成规则菜单编码。
- 菜单编码在全局范围内唯一。
- 菜单编码在编辑场景下不可修改。
- 本期不根据访问类型对菜单路径做差异化校验。
- 删除为物理删除。
- 删除操作需二次确认。
- 删除菜单时，若存在子菜单，提示存在子菜单且不允许删除。
- 批量删除仅对已勾选数据生效；无勾选时不可执行。
- 批量删除时，若任一已勾选菜单存在子菜单，则本次批量删除整体失败，不做部分删除。
- 排序值影响同级菜单展示顺序，值越小越靠前。
- 子菜单列表只展示当前选中菜单的直接子菜单；选中虚拟根节点时展示一级菜单。
- 树形结构与子菜单列表数据需保持一致。

## 5. 验收标准

- 左侧菜单树可通过关键字过滤，展示层级结构清晰。
- 默认选中虚拟根节点，并在右侧子菜单列表展示一级菜单。
- 点击真实菜单树节点后，右侧详情能正确加载对应菜单信息。
- 基本信息 Tab 可完成菜单编辑、保存、校验，能力与编辑菜单页面一致。
- 子菜单列表 Tab 可通过菜单名称、菜单编码查询当前选中菜单的直接子菜单。
- 可完成子菜单新增、编辑、删除、批量删除闭环。
- 新增菜单时，能根据菜单名称自动生成全局唯一菜单编码。
- 删除、编辑、新增操作后，默认返回主页面，刷新列表树、子菜单列表。
- 删除操作有二次确认提示。
- 存在子菜单的菜单不允许删除，并给出明确提示。
- 批量删除遇到任一存在子菜单的菜单时整体失败，不发生部分删除。
- 菜单树与子菜单列表数据展示一致。
- 布局与设计规范一致，符合用户习惯。

## 6. 非功能要求

- 页面交互响应及时，无明显卡顿。
- 表单校验与删除确认提示清晰、友好。
- 树形数据加载时显示加载状态。
- 列表与树形数据展示一致，无明显错位或脏数据。
